# Банско за теб

Публичен портал за благотворителните инициативи на „Банско за теб“ — кампании, дарения, прозрачност и партньорски бизнеси с официални кутии за дарения.

## Текущ статус

Това е първа публична работна версия. Реални банкови данни, лични истории, кампании и партньорски обекти не са добавени без потвърждение от организацията.

## Разработка

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Стек

React 19, TypeScript, Vite, Lucide React, Tailwind/PostCSS.

## Интеграция

Планирана е връзка с Bansko.be за автоматично управление на партньорските бизнеси и баджа „Банско за теб“.
